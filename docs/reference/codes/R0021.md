# R0021: Invalid session

| Severity | PyneCore raises |
|----------|-----------------|
| error    | `ValueError`    |

Message:

```text
`{session}` is not a valid session.
```

A session is one or more `HHMM-HHMM` ranges, optionally followed by `:` and
the days `1` (Sunday) to `7` (Saturday), separated by commas.
